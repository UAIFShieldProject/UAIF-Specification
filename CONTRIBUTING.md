# Contributing to UAIF Specification

Thank you for your interest in contributing to the UAIF project!

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally.
3. **Create a branch** for your changes.
4. **Make your changes** (fix typos, improve wording, add examples, etc.).
5. **Commit** and **push** your changes.
6. **Open a Pull Request** against the `main` branch.

## Areas to Contribute

- **Specification** – improve clarity, add details, fix errors.
- **Examples** – add real-world use cases.
- **Documentation** – write tutorials, translate to other languages.
- **Code** – create reference implementation, unit tests, benchmarks.

## Guidelines

- Keep the **deterministic** and **input-centric** principles intact.
- Use clear, professional language.
- Reference sources where applicable.
