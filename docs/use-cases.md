# UAIF — Use Cases

## 1. Enterprise RAG Systems
Protect corporate AI agents from indirect prompt injection (EchoLeak-style attacks). UAIF filters context extracted from vector databases before it reaches the LLM.

## 2. Financial Services
Prevent billing attacks (Denial of Spend) by sanitising obfuscated input that inflates token counts.

## 3. Government & Military (Air-Gapped)
Deploy UAIF in isolated Kubernetes clusters to ensure full compliance with 152-FZ (Russia) and ISO 27001.

## 4. Chatbots & Customer Support
Protect public‑facing AI assistants from jailbreak attacks via Homoglyph substitution and invisible Unicode characters.

## 5. Research & Education
Use UAIF as a reference implementation for deterministic AI security standards.
